# 配图指南（图类型、美观规范、工具选型）

基于 `建模/` 文件夹官方优秀论文的**视觉抽样分析**：2023/2024/2025 三年 × A/B/C 题各 2 篇 + 2025-E（专科组）1 篇，共 18 篇、每篇精读 5-12 个关键页（样本清单见文末）。所有【语料实证】条目都能回溯到具体论文和页码。图表**数量**基准（图中位 20.5 张、11/14 篇图>表）见 `paper-structure.md` 官方对照一节，本文只谈**画什么图、怎么画、用什么画**。

证据分级沿用 `judge-deductions.md` 的约定：【语料实证】视觉抽样中直接观察到；【语料反例】好坏对照；【公开标准】官方明文；【经验判断】语料看不出来、按工程常识给的建议。

## 一、图类型清单 × 章节位置 × 题型

获奖论文的图分四大类，各司其职：

### 1. 框架图 / 流程图（问题分析章末或各问建模小节开头）

- **全文/单问思路框架图**：模块框+箭头，可加虚线分组框。位置两种都有——放"问题分析"章末（2022 年后惯例，见 paper-structure.md），或放每问建模小节开头（2023-A092 图1"问题一流程图"p4、2023-C228 图16"问题二主体思路"放章首）。【语料实证】
- **算法流程图**：标准语法是"圆角框=起止、矩形=操作、菱形=判断、是/否标注分支"（2024-A016 图10 p18、2025-A196 图9 p15）。近年出现**彩色语义化**版本——用颜色区分节点类型：2024-C038 图8（黄=起止、红菱形=判断、绿=操作）、2025-C132 图13（马卡龙低饱和四色）、2025-C023 图7（四阶段四色分组列）。彩色流程图已是官方优秀论文的常见形态，但配色应低饱和、语义一致。【语料实证】
- 变体：PPT 信息图风格的"里程碑路线"步骤图（2024-B196 图5，点线连节点+旁注小字）也入选官方优秀，属合法变体，正式感略低。【语料实证】

### 2. 示意图（建模过程中，紧贴其解释的概念）

A 题（物理/几何类）的图数大头是它——2023-A092 全文 36 张图里 p4-14 连续 14 张全是几何/光路示意图（坐标系、反射角、遮挡投影、离散化网格），每个关键几何概念配一张。【语料实证】常见手法：

- **黑白线条为主，一种强调色点睛**：2025-A196 用红色勾出"导弹视角下圆柱外轮廓"（图5/6 p13），其余全黑白；2023-A092 几乎纯黑白。示意图克制用色是主流，全彩示意图（2023-B226 图10 蓝面+红轴+船只图标，Word 绘制）也存在但非必需。【语料实证】
- **局部放大**：左全景+右"局部放大示意图"+箭头连接（2024-A016 图12/13 p20-21，调头区域圆弧分析）。稠密几何图必备。【语料实证】
- **3D→2D 配对**：三维场景图旁边放二维截面/投影图帮助读者降维理解（2023-B226 图13"三维空间到二维空间的转化"p13 用大弧形箭头连接左右；2025-A196 图7/8 球遮挡 3D+截面 PAB）。【语料实证】
- **程序输出当示意图**：跑仿真、截取某时刻状态、加标注——2024-A016 图5"碰撞示例"（彩色板凳沿螺线+黑圈标碰撞点）、图9/11 螺线盘绕图。运动学/仿真类问题里比手绘更快更准。【语料实证】
- 领域特定标注图：人体关键点+角度编号+图例（2025-E030 图11 p11）。【语料实证】
- 绘制工具多样且都被接受：Word/PPT 自绘（B226）、CAD（2023-B311 图2-5，文中明说"运用 CAD 绘制"）、Visio 风格、matplotlib patches（2024-A178 附录 Plot 脚本用 plt.Polygon 画板凳）。【语料实证】

按题型分主力图型（均为语料实测出现）：

- **(a)(b) 子图规范**：一组强关联的图合并为一个图号，各带子图题，再加总图题（2023-C228 图7/8：`(a) 每日总销量自相关函数图 (b) 每日总销量时间序列分解`＋总题"周总销售量周期性分析"）；或图题内注明"（左图）（右图）"（2023-A127 图9）。【语料实证】
- **图后解读三种范本**：① "根据图9，我们可以得出如下结论：●加粗要点…"（A127 p14）；② 图旁挂虚线边框文字解读框，加粗关键结论（B226 p9 每张数据图配一个，Word 文本框环绕）；③ 图后普通段落但含具体数字（"下肢角度由 149° 变到 99°"，E030 p12）。共性是**图后必有解读、解读里有数字**。【语料实证】
- 结果图不必全塞正文：2023-C126 正文仅 8 张图，13+ 张 MCMC 诊断图以 jpg 形式放支撑材料，正文只留承担论证的关键图。**"诊断类/过程类图放支撑材料"是控制图数膨胀的正解**。【语料实证】

### 4. 检验/灵敏度图（检验章或各问尾部）

- 参数扫描多曲线（B226 图6-8）、误差棒-噪声水平图（B157 图22）、**半透明色块标注选定区间**（B157 图27 的 band_used 色块——"模型适用范围"可视化）。【语料实证】
- 灵敏度**用表也完全合法**：2024-C094 表3/4 左右并排双小表（p、q 扫描）；2025-C023 表5 带"相对位移 Δt"列直接量化扰动影响。图不是唯一形式，关键是"扫哪个参数、结果说明什么"（见 judge-deductions.md 建模组）。【语料实证】

### 表格的强调手法（顺带，因与图同为视觉呈现）

黄色高亮最优单元格+表注说明（2024-B159 表4）；是/否布尔表用深浅蓝填充（2024-B196 表1）；异常值加黑体+表题注明规则（2025-B060 表4"标准偏差大于 3σ 的异常值标记黑体"）；斑马纹隔行底色（2025-C023 表4/5）；长表中间行"…"截断+指向支撑材料（2023-A127 表2/3"全部数据详见支撑材料(文件十-工作表1,2)"）或"[注]：由于篇幅限制，其余见附录"（2025-E030 表7/8）；统计学报告表给均值/标准差/95%CI/CV 而非单值（2025-B060 表5）；同构表格系列化呈现多场景（2025-C132 表3-6 四种准确率策略）。【语料实证】

## 二、美观规范

- **图题位置**：图题在图下、表题在表上（LaTeX 源码核对无一例外，见 writing-style-guide.md）。图题格式"图 N 题名"或"图 N: 题名"（LaTeX），编号风格全文统一。【语料实证】
- **配色**：数据图彩色、示意图黑白+单强调色是主流分工（A127/A196 最典型）。数据图常见三种取色：matplotlib/MATLAB 默认循环色（大量论文直接用，完全可接受）、科研常用的"华夏配色"类自定义十六进制（2024-A178 附录源码：`#C82423` 红/`#2878B5` 蓝）、低饱和马卡龙（C132 流程图）。避免高饱和大面积撞色。【语料实证】
- **中文字体**：语料里两种现实做法——配好中文字体让图内标签全中文（多数 Word/MATLAB 论文），或图内全英文+图题中文规避乱码（2025-B060 图8、B157 全篇"Raw Data/Detrended"）。后者可用但同篇内英中混杂（B060 图8 英文/图9 中文）显得不统一。**推荐前者**：matplotlib 配 `rcParams['font.sans-serif']` 中文字体链+负号修复（见 snippets/plotting/style.py）。获奖队 GitHub 源码实测中这两行（`font.sans-serif=['SimHei']` + `axes.unicode_minus=False`）在几十个绘图脚本里反复出现，是事实上的标准开头。【语料实证】
- **字号**：以缩印/扫描后仍可读为准——2024-C094 图6 轴标签过小，85dpi 扫描后已不可读，是反例。经验值：图内最小字号 ≥ 正文字号的 70%（matplotlib 默认 10pt 配 5 英寸宽单栏图基本达标，缩放图片时字号同步缩放是主要风险）。【经验判断】
- **分辨率/导出**：用 `savefig`/`exportgraphics` 导出（PNG ≥300dpi 或矢量 PDF/SVG），**不要截屏**——2023-B311 图11 右上角残留 MATLAB 窗口工具栏图标、图8 顶部标题被截断，是截屏导出的典型痕迹（该篇仍入选官方优秀，说明评委重内容，但这是零成本可避免的粗糙感）。【语料反例】
- **图内标题与图下题注不要重复**：MATLAB/matplotlib 的 `title()` 自动标题与图下题注内容重复（B311 图7"地形图"、C228 多图），轻微冗余、常见但不推荐——图内标题留给子图题或省略，正式题注放图下。【语料实证+经验判断】
- 关键结论可直接标注在图内（A127 图10 云图上写"日平均光学效率=0.5759"）；无图例时图后用文字逐元素解释（B311 图6"红色虚线所围成部分为待测海域，蓝线为测线"）。【语料实证】
- **反面清单**（语料实测或公认，交稿前逐图自查）：截屏带工具栏/窗口边框；等高线数值标注重叠不可读（B311 图8）；轴标签缺单位；同篇图题格式不统一；3D 饼图——2023-C228 图12 用了 Excel 3D 饼图（(a)(b) 两个），确实入选官方优秀，但 3D 饼图的角度失真是数据可视化公认缺陷，**语料存在≠建议效仿**，占比数据用普通饼图/条形图/帕累托图替代。【语料反例】

## 三、工具选型与生成路线

### 数据图：必须用代码从真实计算结果生成（matplotlib 首选）

理由是硬的：① 论文图的每个数字都可能被评委与正文核对，**图文数字不一致比没有图严重得多**；② 附录要交代码、结果要可复现，图必须能从代码重新跑出来；③ 修改模型后重跑一条命令即可更新全部图。

获奖队实际工具链（语料实测）：MATLAB（2023-A127/B311）、Python matplotlib/seaborn（2023-C228、2024-A178/C038、2025-B060/B157/E030）、Excel/EViews（2023-C126）、混合（B311"利用 Matlab 和 Python 求解"）。**工具本身不影响评审，但 Python/matplotlib 是本工具箱的推荐路线**，脚手架见 `snippets/plotting/`。

**获奖队 GitHub 仓库源码实测**（7 个含源码的语料仓库，见 corpus/manifest.md：yan-fanyu/CUMCM-Paper-And-SourceCode 覆盖 2021-A/B/C、2024-B/C 五题最大宗、seanys/CUMCM2020-Desert-Game 国一、linggm3/2023_CUMCM_National-First-Prize 国一等）：

- **Python 是主流**：45 个 .py 文件用 matplotlib（其中 10 个另用 seaborn），MATLAB 也大量存在（110 个 .m 文件含绘图调用，尤其 linggm3 国一仓库全用 MATLAB）——两条技术栈都能拿国一，选择看队伍熟悉度，不影响评审。
- **中文字体设置几乎是复制粘贴的两行**：`plt.rcParams['font.sans-serif'] = ['SimHei']` 和 `plt.rcParams['axes.unicode_minus'] = False` 在源码中出现数十次，是 matplotlib 中文图表事实上的标准开头。
- **图类型频率**（45 个用 matplotlib 的文件）：`plt.plot`（折线，75 次）远超其他类型，`plt.scatter`（散点）、`sns.heatmap`/`sns.barplot`（seaborn 热力图/条形图）次之——与视觉抽样一致，折线图是绝对主力。
- **dpi 设置不统一但存在**：仅 41 处 `savefig` 调用中 6 处显式指定 dpi（如 `dpi=300`、`dpi=24*12`），多数留默认（100dpi，偏低）。**建议脚手架显式默认 300dpi**，不要沿用"多数队伍不设"的现状。
- **figsize 常见取值**：`(12, 6)` 最多见，其次 `(10, 6)`——横向矩形、双栏或单栏大图皆可用的通用比例。
- **`plt.annotate` 用于给数据点标注具体数值**（如条形图上标 `f'{value:.2f}'`）——呼应"图内直接标注关键数字"的规范（见二、美观规范一节）。
- MATLAB 端常见做法：数值方法生成散点/圆周离散点后 `scatter`+`plot`+`axis equal` 检查几何关系（linggm3 仓库 `concentric_circles.m`），多为调试用图、未必进最终论文——印证"正文图是从探索性调试图里精选出来的"。

2024-A178 的支撑文件组织值得抄作业：`Problem{N}_{k}.py`（求解）与 `Plot{N}_{k}.py`（每张论文图一个独立绘图脚本，注释写明画的是哪张图）+ `Table.py`（导出结果表）分离——图的可复现性直接写进文件结构。【语料实证】

### 框架/流程/示意图：mermaid / draw.io / PPT / matplotlib patches

- 流程图、框架图：draw.io 或 PPT 手绘最快，mermaid 适合先在文档里打草稿再重绘；配色参考第二节（低饱和、语义一致）。
- 几何示意图：matplotlib patches（可精确控制坐标，A178 用 `plt.Polygon` 画板凳）、GeoGebra、CAD（B311 先例）、PPT。原则：黑白线条+单强调色、中文标注、能与正文符号表对应。

### gptimage2 等 AI 生图：备用路径，边界很窄

**严禁用于任何含数据、坐标轴、数值刻度的图**——生成模型画的坐标轴和曲线是编造的，图文不符风险不可接受，且无法复现。唯一勉强可用的场景：**不承载任何定量信息的物理场景示意图/封面装饰图**（例如"海面波浪中的浮子装置"这类氛围性示意），且要满足：

1. 图中不出现（或后期用绘图工具覆盖）任何数字、坐标、中文标签——AI 生图的中文文字渲染极易出错；
2. 论文其余部分对该图的引用只作定性说明，不从图中读取任何量；
3. **按官方规定披露**：《全国大学生数学建模竞赛人工智能工具使用规定（2025 年试行）》（[官方 PDF](https://www.mcm.edu.cn/upload_cn/node/756/A2YEa52s04e7e3c157970a10534eee1fb9397f54.pdf)，[中国大学生在线转发页](https://dxs.moe.gov.cn/zx/a/hd_sxjm_gsyw/250904/2017973.shtml)）要求：使用 AI 生成的内容须在**正文相应位置标注**，并在**参考文献中列出所用工具**（格式：`[编号] 工具名称，版本/型号，开发机构/公司，使用日期`）；未使用 AI 的队伍也须在参考文献后声明"本参赛队未使用任何AI工具"。核心建模与分析必须由参赛队独立完成。【公开标准】

提示词模板（仅限上述边界内使用）：

> A clean schematic illustration for an academic paper: [场景描述，如 a cylindrical wave-energy buoy floating on ocean waves, cross-section view]. Minimalist line-art style, white background, no text, no numbers, no axis, muted colors, technical drawing aesthetic.

要点：`no text, no numbers, no axis` 必须写；风格锚定 line-art/technical drawing 避免照片感；生成后自己用绘图工具叠加中文标注。**实践中语料 18 篇里没有一张图需要走这条路径**——几何示意用 matplotlib/PPT 画得又准又快，这条备用路径的预期使用频率应接近零。

### 每张图的最低要求（写作手/编程手交接清单）

1. 图前正文有引导句、图后紧跟带数字的解读（见 writing-style-guide.md 图表规范）
2. 轴标签带单位、中文不乱码、图例齐全或图后文字解释
3. 由 `Plot*.py` 类脚本生成、脚本入支撑材料
4. 导出非截屏、无工具栏/水印残留
5. 图题在图下、编号与全文风格一致

## 四、样本清单与方法
