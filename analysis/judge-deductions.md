# 评委扣分点清单

赛时交稿前的自查清单，供论文手/整合者逐条勾选。每条标注证据类型：

- **【语料实证】** 25/37 篇语料的共性数据支撑，出处见 `paper-structure.md`（结构/篇幅）或 `writing-style-guide.md`（写作规范）
- **【语料反例】** 语料内部质量分层的具体对比——某篇明显做得好、某篇明显做得差，两者对照
- **【公开标准】** CUMCM 官方评审规则或明文赛制要求，非语料归纳
- **【经验判断】** 语料无法直接验证、但符合建模常识的判断，本文尽量少用

不复述 `paper-structure.md`（章节骨架/篇幅占比）与 `writing-style-guide.md`（人称/图表/公式/参考文献规范）已有的结论，仅链接引用。

## 摘要

- [ ] 摘要能否脱离正文单独理解——不看正文，仅凭摘要能否说清"做了什么、怎么做的、结果如何"？【公开标准】官方评奖标准为"假设的合理性、建模的创造性、结果的正确性、文字表述的清晰程度"四条（常被参赛者简称"三性"，但官方原文是四条，非三条），"表述清晰程度"直接对应摘要自足性；"评委首轮阅卷主要看摘要、初评定级只能上调不能下调"是参赛者中一致的经验之谈，但未查到官方明文条款，此半句降级为经验判断。
- [ ] 论文中是否出现学校名称、队员姓名、参赛编号等可能暴露身份的信息？【公开标准】《全国大学生数学建模竞赛论文格式规范》明确要求摘要页、正文、附录乃至电子版文件名/文件夹名/文档属性均不得含身份信息，违反者按无效作品处理、直接取消评奖资格——这是所有检查项里唯一可能导致"零分"而非"扣分"的一条，且摘要页是评委看到的第一页，务必最后核查一遍。
- [ ] 每个子问题的方法名是否与一个具体数字紧邻出现，而不是"首先...然后...最后"的空洞过程描述？【语料实证】2023-A"蒙特卡洛光线追迹法...年均光学效率61.58%"、2024-B 摘要给 138/97 抽样数，是数字密度高的强写法范本，见 `writing-style-guide.md` 摘要语言一节。
- [ ] 摘要里的结果是否直接给出数值，而不是"见文中表X"这种把数字甩给正文的写法？【语料反例】2005-B（特等奖）摘要多处用"见文中表2、表3"代替直接写数字（如购买量、分配方案未在摘要内给出具体值），对比同样特等奖的写法，摘要仍应把关键数字留在摘要本身，表格是给正文读者复核用的，不能替代摘要的自足性。
- [ ] 摘要第一句是否直接点出研究对象+方法，而非"随着社会发展/近年来"式通用铺垫？【语料实证】抽查未发现获奖论文摘要以此类套话开头（如 2022-A 首句即完整给出问题与方法），见 `writing-style-guide.md`。
- [ ] 摘要方法描述是否具体到算法名（蒙特卡洛/微分方程/整数规划等），而非"建立数学模型进行求解"这种可以套用到任何题目的空话？【语料反例】对比 2022-B-2（省二，全文最短约5200字）摘要"利用圆周角定理...再次利用已经构建的无源定位模型解决新类型问题"——方法名有但缺具体结果数字，通篇摘要无一个量化结论，与 2023-A/2024-B 的数字密集型摘要形成明显反差。

## 假设

- [ ] 假设列表里的每一条，是否都能在后续建模部分找到对应的简化或忽略？【语料实证】2022-A（国一）假设2.1"水面近似静止（微幅波，水面波动不纳入考虑）"直接对应 4.1 问题一分析"题目要求只考虑振子和浮子在竖直方向上的运动"；假设2.6"不产生形变"对应五、模型建立里的刚体动力学方程——假设与建模逐条可对应，是紧耦合的范例。
- [ ] 建模部分是否用到了某个简化，但假设列表里根本没写这一条（反向脱节）？【经验判断】语料抽查未定位到确凿反例（多数语料论文假设条数 4-8 条、覆盖面较全），但这是队内写作常见失误——建模中途"为简化计算，我们不考虑…"却未同步补进假设章，自查时应逐条核对模型部分出现的"不考虑/近似/忽略"是否都能回溯到假设章。
- [ ] 每条假设是否带一句理由，而不是干巴巴地列条目？【语料实证】2022-A 每条假设括号内注明为何合理（"由于是微幅波，因此水面的上下波动不纳入考虑"），2024-B 每条配"这一设定是为了…"，是好范例；见 `paper-structure.md` 模型假设一节。
- [ ] 假设是否被模型评价部分自我推翻却未修正？【语料实证】2022-A 在 7.4 模型推广中诚实指出"水面高度的改进：在遇到较大的波浪时，假设2.1就不成立了"——诚实标注假设失效边界是加分项，而不是假装假设永远成立。
- [ ] 全局假设章是否存在，而不是把假设拆散到各问小节里？【语料实证】25 篇可测量论文中仅 2024-C-2 无全局假设章、假设下沉到 6.2.2 按问题给出，`paper-structure.md` 指出"可行但不推荐——全局假设章更便于评委检查"。

## 建模与求解

- [ ] 灵敏度/敏感度分析是否包含"扫哪个参数、为什么选它、结果说明了什么、对结论有什么影响"这四个要素，而不是"调一个参数画个图"？【语料反例】2022-A（国一）敏感度分析对激励力振幅做扫描，给出具体失效阈值（"问题二中激励力振幅超过5500""问题四激励力矩振幅超过6932.31时推导可能失效"）并据此圈定模型适用范围，四要素齐全；对比 2018-A 的"6 模型检验"仅做数值方法的误差/收敛性验证（有限差分反演法核对收敛率），未对任何建模参数做灵敏度扫描，是"检验"与"灵敏度分析"混为一谈的典型——自查时区分这两者，数值方法误差验证不能替代对建模结论稳健性的检验。
- [ ] 图表后面是否紧跟一句解读，而不是贴图就转下一个公式？【语料实证】写作规范一节（`writing-style-guide.md` 图表规范）抽查多篇未发现"只贴图不解读"的反例，图前引导句、图后解读句是语料主流；仍应作为自查项逐图核对。
- [ ] 数据来源是否写清楚——题目附件给的、自己查/爬的、还是假设的？外部数据是否标注出处？【语料实证】2010-B（全国一等奖）每个数据表都标注来源（"数据来至上海统计局网站[3]""数据来至《上海统计年鉴》"），并在参考文献里给出可核查的链接，是清晰披露的范例。
- [ ] 承担关键作用的参数（直接决定最终结果的系数）是否有依据，而不是凭空给一个数字？【语料反例】2024-C-2（省二）6.2.2 节"我们假定预期销售量为当年总产量的80%"无任何引用或推导，但这一数字直接驱动全文优化目标和最终利润结果——凡是一改就变结论的参数，必须有出处或至少标注为"经验假设"并说明选取依据，不能悄悄硬编码。
- [ ] 建模部分是否占比过低、被压缩成走过场，正文重心是否偏移到别处（如整段贴代码/贴原始笔记）？【语料反例】2024-A-2（未完赛提交）建模求解部分仅占提取正文的约 30%（远低于语料 25 篇 60-80% 的常态区间），而附录（含大段带乱码注释的 Python 代码）膨胀到约占全文 56%；虽然摘要和五个子问题的框架都写了，但求解深度被压缩、疑似赶工产物，是结构完整但明显偷工减料的反面教材。
- [ ] 每个子问题的答案是否能在正文中直接定位，而不需要读者自己拼凑多处结果？【经验判断】源自模板假设，语料中未见明显反例（各篇均有清晰的问题分段结构），但仍是赛时最容易在时间压力下疏漏的一项——最终定稿前建议按题目逐条核对"这一问的最终答案句子在哪"。

## 检验与代码

- [ ] 代码是否放进附录而非占用正文篇幅？【语料实证】2022-2025 年 14 篇中 2022-A、2022-B-1、2022-C、2023-A、2023-C、2024-A-1、2024-A-2、2024-C-1、2025-C 均在附录中内嵌实际代码（含 import/def 等关键字），2025-A（LaTeX 源码）用 `\lstinputlisting` 外链代码文件，同样符合"代码不占正文"的原则。
- [ ] 附录代码是否是"占位"——代码是否放进附录不代表可以不做，语料显示代码入附录并非 2022 年后的绝对必选项？【语料反例】2023-B（国家二等奖）、2024-B（省一等奖）、2024-C-2 三篇提取文本中均检测不到附录/代码内容——2024-B 是省一水平仍获奖，说明"代码必须入附录"不是硬性门槛，但也提示：若确实写了代码却没有附上，评委无法核实复现性，能附尽量附，缺附录不代表会被扣分，但补上只有好处没有坏处。
- [ ] 正文是否有"代码见附录 X"这类交叉引用，方便评委核对？【语料实证】17/37 篇（46%）在正文明确写了"见附录"类引用，2022 年后"附录A：支撑文件/材料列表"渐成标配，见 `writing-style-guide.md`；不做不算硬伤但做了体验更好。
- [ ] 模型评价部分是否诚实指出局限，而非一眼假大空的自我表扬？【语料反例】对比 2008-A"旋转矩阵R的求解不能非常清晰明确的给出，需要进一步完善"（诚实标局限）与 2024-C-2 模型优点"我们建立的模型完美地考虑了轮作条件"（"完美"一类绝对化自夸用语，语料里较少见、读来突兀）——凡是用"完美/绝对/一定"等绝对化措辞描述自己模型优点的句子，建议在定稿前逐句核查并换成有保留的表述。
- [ ] 模型评价的缺点部分是否具体到"什么条件下会失效"，而不是泛泛一句"模型有一定局限性"？【语料实证】2018-A 缺点部分具体到"空气层与假人皮肤外侧之间的距离小于6.4mm时不考虑热辐射""附件二数据求解时一部分δ的值出现正值"这类可核查的具体失效条件，是好范例。

## 表述与合规

- [ ] 参考文献是否至少 2 条、体现真实检索而非凑数？是否包含 1-2 篇与赛题直接相关的近 3-5 年期刊/会议文献，而不是清一色通用建模教材？【语料实证】"至少5条"在语料中站不住（2019-A 国一范文仅3条），但近年国一/省一论文（2023-A 8条全 [J]、2024-B 6/7条 [J]）明显更依赖切题的近年期刊文献，详见 `writing-style-guide.md` 参考文献一节。
- [ ] 参考文献格式是否统一采用 GB/T 7714（[J]/[M]/[D] 类型标识），而不是新旧格式混杂？【语料实证】2020年后论文普遍规范使用类型标识，早年论文常见无标识或纯网址，建议新论文统一按 GB/T 7714 书写，见 `writing-style-guide.md`。
- [ ] 图表编号、公式引用是否全文风格一致（连续编号或分章编号二选一，不要混用）？【语料实证】26/33 篇以连续编号为主、7/33 篇以分章编号为主，两者均有获奖论文，但同一篇论文内部必须统一，见 `writing-style-guide.md` 图表规范一节。
- [ ] "显然""易知"等跳步用语出现前，是否自问"去掉这两个字读者能否凭上文推出结论"？【语料实证】37篇里14篇出现过，多数每篇仅1-2次，非重灾区但确实存在跳过推导的个例，见 `writing-style-guide.md`。
