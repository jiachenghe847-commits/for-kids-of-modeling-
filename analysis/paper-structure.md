# 论文骨架结构分析

基于 corpus/ 下 37 篇获奖论文（2002-2025）的共性归纳。其中 25 篇结构完整、可按章节切分做定量测量（见文末「测量口径与样本」）；篇幅占比为**实测值**，非经验估计。

## 标准骨架（按出现顺序）

占比 = 该章节字符数占正文（摘要起、参考文献前）的百分比，基于 25 篇可测量论文；给出的是典型区间（大多数论文落在其中），括号内为中位数。

| 章节 | 篇幅占比（实测） | 要点 |
|---|---|---|
| 摘要 | 5-9%（7.8%） | 约 700-1100 字，基本写满第一页。主流写法：首段一两句话总起全文方法框架，然后**逐问一段**「针对问题 X，用了什么方法，得到什么结果」，结果必须给具体数字——如 2024-B 摘要直接给出 95%/90% 信度下最小抽样数 138/97，2023-A 给出年均光学效率 61.58%、0.599kW/m²，2019-A（国一范文）给出最优开启时长 0.29ms。关键词 4-8 个，方法名为主 |
| 问题重述 | 4-8%（5.2%） | 主流分 1.1 问题背景 + 1.2 问题提出两小节；背景 1-2 段，逐问用自己的话重述，不照抄题干 |
| 问题分析 | 4-10%（7.4%） | 每个子问题一小节（2.1 问题一的分析…），写清建模思路和**为什么选这个方法**；2022 年后常在本章末尾放一张全文思路框架图（2024-B、2025-C 均有「图 1 思路框架图」） |
| 模型假设 | 1-3%（1.3%） | 比传言的「3-5%」短得多——实测 25 篇里 20 篇不到 2%。通常 4-8 条；好论文每条附一句理由，如 2022-A（国一）每条假设括号里注明为何合理（「由于是微幅波，水面波动不纳入考虑」），2024-B 每条配「这一设定是为了…」 |
| 符号说明 | 1-4%（1.5%） | 表格形式，列出全文性符号，现代论文多带「单位」列；局部符号可在小节内现场定义，2023-A（国一）在表尾注明「在具体的模型中，将对符号进行分别说明」 |
| 模型的建立与求解 | 60-80%（70.8%） | **远超传言的 40-50%**，是全文绝对重心。每个子问题：建立 → 求解 → 结果分析三段式。两种组织法都常见：单章多节（五、模型的建立与求解 → 5.1/5.2/5.3 问题一/二/三），或每问独立成章（2021-C、2025-C、2025-A：「五、问题一模型的建立与求解」「六、问题二…」），后者在近年更多见 |
| 模型检验 / 灵敏度分析 | 独立成章时 2-9%（4.9%） | 25 篇中仅 8 篇独立成章；其余嵌在各问求解小节尾部（2022-C 的 5.3.5、2016-B 的 5.3.6）。无论放哪，都要交代扰动哪个参数、为什么、结果说明什么——2022-A 对激励力振幅做敏感度分析并据此给出模型适用的海浪大小范围，是好范例 |
| 模型评价（优缺点）与推广 | 2-7%（4.1%） | 优点、缺点分列，再加改进/推广方向；诚实写局限（2008-A 直接写「旋转矩阵 R 的求解不能非常清晰明确的给出，需要进一步完善」） |
| 参考文献 | 极短 | 5-15 条为常态，GB/T 7714 格式 |
| 附录 | 不占正文 | 代码 + 数据表。2022 年后「附录 A：支撑文件/材料列表」成为标配（2022-A、2024-A-1、2024-C-1 均有），对应赛制的支撑材料要求；正文中引用「程序见附录 X」 |

## 观察到的合法变体

骨架不是死格式，语料里这些偏离都出现在获奖论文中：

- **前四章次序两派**：主流是「重述 → 分析 → 假设 → 符号」；少数派「重述 → 假设 → 符号 → 分析」（2008-A、2016-A、2017-A、2022-A），两派都有国一。
- **分析并入第一章**：2025-C（省一）用「一、引言」内含 1.1 问题背景 + 1.2 问题分析，不设独立分析章。
- **模型准备/数据预处理独立成章**：数据密集型题常见——2010-B「数据收集与分析」、2012-A-2「模型的准备」、2019-A「五、模型准备」。C 题（数据分析类）尤其值得预留这一章。
- **内容命名章标题**：2020-B-1（国一，LaTeX 源码）完全不用「模型的建立与求解」这种通名，章名直接是「全程天气状况已知条件下的最优策略」「多玩家博弈条件下的策略」，且无独立假设章。说明评委看的是内容组织是否清晰，不是章名是否标准。
- **假设下沉到各问**：2024-C-2 无全局假设章，在 6.2.2 里按问题给假设。可行但不推荐——全局假设章更便于评委检查。

## 年代差异（2022-2025 vs 更早）

对 2026 备赛，近三届的形态最值得对齐：

- **图表密度约 3 倍增长**：篇均图数 7.6（2002-2018，n=10）→ 15.8（2019-2021，n=5）→ 20.3（2022-2025，n=10）；表数 9.3 → 7.4 → 12.3。现代获奖论文约每页一图，思路框架图、流程图、结果可视化都是标配。
- **附录带全量代码**：附录（代码为主）占提取文本的比例，平均从约 20%（2002-2018）升至约 49%（2022-2025，2024-A-1 达 79%、2023-A 67%），且配支撑文件清单；早年多为程序节选。
- **正文体量稳定**：各年代正文字符数均值都在 1.2-1.3 万，摘要稳定在 800-1000 字——篇幅要求 20 多年没变，变的是图表和代码附件的完整度。
- **每问独立成章的写法增多**：便于评委按问核对，也便于队内分工并行写作。
- **摘要的「数字密度」变高**：近年国一摘要几乎每问都落到具体数值结论；早年（如 2005-B 特等奖，摘要仅 304 字）更简略。

## 测量口径与样本

- 占比按 pdftotext 提取文本的 CJK+字母数字字符数计，正文 = 摘要起点到参考文献之前。公式、表格密集的章节（主要是建模求解）会被略微高估，但不影响量级结论。
- 可测量 25 篇：2005-B、2008-A、2010-B、2012-A-1、2012-A-2、2015-A、2016-A、2016-B、2017-A、2018-A、2019-A、2019-B、2020-C、2021-B、2021-C、2022-A、2022-B-1、2022-B-2、2022-C、2023-A、2023-C、2024-A-1、2024-B、2024-C-1、2025-C。
- 排除 12 篇及原因：2020-B-1、2025-A 为 LaTeX 源码（结构已参考、不参与字符统计）；2023-B 为期刊重排版（结构完全期刊化，非赛制骨架）；2024-A-2 为未完赛提交；2008-B 为逐问自带假设/符号的非典型结构；2012-B、2014-C、2017-D、2018-C、2021-A 的 pdftotext 提取标题损坏或乱序，无法可靠切分；2020-B-2 正文疑似截断；2024-C-2 无独立假设章且疑提取不全。
- 语料仅覆盖本科组 A/B/C 题；D/E（专科组）无公开全文来源，本文结论不适用于专科组题型（见 corpus/manifest.md）。
