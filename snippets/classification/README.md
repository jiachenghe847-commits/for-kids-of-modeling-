# 分类（判别 / SVM / 决策树 / 随机森林 / 朴素贝叶斯 / Logistic）

**什么时候用**：有**带标签**的训练样本，要学出规律去判别新样本属于哪一类（信用好坏、疾病有无、产品合格与否）。和聚类的区别：聚类无标签、自己分堆；分类有标签、学"输入→类别"的映射。

**六种方法怎么选**：
| 方法 | 适合 | 特点 |
|---|---|---|
| `lda_classify`（Fisher 判别） | 类别近似正态、线性可分 | 经典、可解释、快；也能降维 |
| `svm_classify`（支持向量机） | 中小样本、边界非线性 | 精度高，`kernel="rbf"` 处理非线性 |
| `tree_classify`（决策树） | 需要"能讲出规则"的场景 | 可解释性最好，易过拟合 |
| `random_forest_classify`（随机森林） | 想要稳、准、还要特征重要性 | 精度稳，解释性弱于单棵树 |
| `naive_bayes_classify`（朴素贝叶斯） | 小样本、特征近似独立 | 快、稳，能输出类别概率 |
| `logistic_classify`（Logistic 回归） | 要解释"各因素如何影响发生概率" | 系数/优势比可直接写进结论 |

拿不准就先用随机森林拿个 baseline，再看要不要换更可解释的。**要在论文里讲清"哪个因素起多大作用"，优先 Logistic 或决策树。**

**参数怎么调**：SVM 的 `C` 越大越拟合训练集（过拟合风险）、`kernel` 线性不够就用 `rbf`；决策树/随机森林的 `max_depth`、`n_estimators` 控制复杂度；LDA/SVM 已内置标准化。

**结果怎么解读**：`accuracy` 是**训练集**准确率，会偏乐观——真实效果必须用 `snippets/model_validation/` 的交叉验证评估。`tree`/`random_forest` 额外给 `feature_importance`，可说明"哪些指标对分类最关键"；`logistic_classify` 给 `coef` 与 `odds_ratio`（优势比 >1 表示该因素提高发生概率，<1 表示降低），是很好的论文结论点；`naive_bayes`/`logistic` 还有 `predict_proba` 可给出概率而非硬分类。类别不平衡时准确率会骗人，要看混淆矩阵/召回率。

**常见坑**：
- 只报训练集准确率——评委必查泛化/交叉验证，务必做
- 类别严重不平衡（如 95% 正常、5% 异常）时，全判正常也有 95% 准确率——要看查准/查全
- SVM 不标准化直接跑（本脚手架已用管道规避，自己改时注意）
- 决策树不限深度直接跑到 100% 训练准确率——典型过拟合
