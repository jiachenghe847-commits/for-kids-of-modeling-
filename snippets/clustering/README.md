# 聚类分析（K-Means / 层次聚类）

**什么时候用**：把样本按相似度分成若干组（分类问题里"没有现成标签、要自己把数据分堆"的那一类）。典型场景：把城市/客户/样本点分群，或给后续分类/评价先做分组。有标签要预测类别用的是判别/神经网络分类，不是聚类。

**参数怎么调**：
- 簇数 `k` 是关键，别拍脑袋——先用 `best_k_by_silhouette` 扫一遍 2~7，看轮廓系数最高的 `k`（也可配合肘部法看 `inertia` 拐点）。
- 聚类前**必须先标准化**（见 `snippets/preprocessing/`），否则量纲大的特征会主导距离。
- 层次聚类 `linkage` 默认 `ward`（最常用），簇形状怪异时试 `average`。

**结果怎么解读**：`labels` 是每个样本的簇编号；`silhouette` 轮廓系数在 -1~1 之间，越接近 1 分群越干净，<0.25 说明分群勉强、要重新考虑 `k` 或特征；`centers` 是各簇中心，可用来给每一类起名/画像。

**常见坑**：
- 不标准化直接聚类——距离被大量纲特征绑架，结论无意义，评委常在这里扣分
- 直接报 `k` 而不说明怎么定的——正文里要给出定 `k` 的依据（轮廓系数/肘部图）
- K-Means 对初值敏感，代码已设 `n_init=10` 和固定 `seed` 保证可复现，论文里要写清随机种子
