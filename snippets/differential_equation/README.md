# 微分方程模型（ODE 数值解）

**什么时候用**：题目描述的是随时间/空间连续变化的过程，且变化率能写成方程——传染病传播（SIR/SEIR）、种群增长（Logistic/Lotka-Volterra）、传热扩散、物理运动、药物代谢等。能解析求解的简单方程直接算；复杂/非线性方程用这里的数值解。

**参数怎么调**：
- `solve_ode` 是通用入口，自己写右端函数 `func(t, y, *args)`；`sir_model` 是可直接套的传染病示例。
- 模型系数（如 `beta`、`gamma`）是重点：优先用数据拟合反推（配合 `snippets/regression/` 或 `snippets/metaheuristics/` 做参数估计），不要凭空取值。
- `method` 默认 `RK45` 够用；刚性方程（各分量变化尺度差很大）改用 `"Radau"` 或 `"BDF"`。

**结果怎么解读**：`t` 是时间点，`y` 是各状态变量随时间的解（每行一个变量）；`success=False` 说明数值积分失败（步长/刚性问题），要换 method 或检查方程。传染病模型看 I 的峰值时间和峰值高度是常见结论点。

**常见坑**：
- 参数直接拍脑袋给、不做拟合或灵敏度分析——评委会问"凭什么是这个值"，务必配合 `snippets/model_validation/` 的 `sensitivity_analysis`
- 初值/单位不一致（比例 vs 绝对人数混用）
- 刚性方程用 RK45 会极慢或不收敛，要换隐式求解器
