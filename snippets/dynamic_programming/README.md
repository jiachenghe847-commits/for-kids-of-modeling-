# 动态规划（DP 模板）

**什么时候用**：问题能拆成**重叠的子问题**、且**最优解由子问题最优解拼出**（最优子结构）——分阶段决策、资源分配、路径计数、序列匹配等。特征信号：问"最多/最少/有多少种方案"，且当前决策只影响一个"状态"往后的部分。

**这里给的是 3 个最常见模板，照着改**（DP 的关键是"定义状态 + 写转移方程"，很难做成一个通用函数，所以给可套用的范式）：
| 模板 | 解决的问题原型 | 可类比的赛题 |
|---|---|---|
| `knapsack_01` | 0-1 背包：选或不选、容量受限下最大化收益 | 有限预算/容量选项目、装载、投资组合（离散） |
| `longest_increasing_subsequence` | 最长递增子序列 | 趋势/单调段提取、序列对齐类 |
| `coin_change` | 凑金额的最少个数 | 面额/规格拼凑、最少步数类 |

**参数怎么调**：无超参数。注意 `knapsack_01` 要求**重量和容量是整数**（DP 表按容量离散）；重量是小数时先按精度放大取整，或改用 `snippets/linear_programming/` 的整数规划 `solve_milp`。

**结果怎么解读**：`knapsack_01` 给最大价值和被选物品下标；`longest_increasing_subsequence` 给长度和一个具体子序列（可能不唯一）；`coin_change` 凑不出返回 -1。

**常见坑**：
- 状态定义没说清就写代码——论文里 DP 必须写出"状态定义 + 状态转移方程 + 边界"，这是评委看你是否真懂的地方，不能只贴代码
- 背包容量很大（如 10^7）时二维 DP 会内存/时间爆炸，要滚动数组优化或换整数规划
- 把不满足"无后效性/最优子结构"的问题硬套 DP
- 重量非整数直接喂进来——`knapsack_01` 会因索引问题出错，先离散化
