# 模糊综合评价

**什么时候用**：评价对象的等级带有模糊性、用"优/良/中/差"这类语言评语而非精确分值时（水质评价、满意度、风险等级等）。指标能直接量化打分排序的，用 TOPSIS/熵权更直接。

**参数怎么调**：
- 核心输入是**隶属度矩阵 `R`**：每个指标对各评语等级的隶属度，来自隶属函数（三角/梯形/正态）或专家打分，这一步的依据必须在正文写清楚。
- `weights` 指标权重不要凭空定——配合 `snippets/ahp/`（主观）或 `snippets/topsis_entropy/` 的熵权法（客观）得出。
- 指标分层多时用 `fuzzy_evaluate_multi` 做两级评价。

**结果怎么解读**：`membership` 是综合隶属度向量，`level_index` 按最大隶属度原则给出的最终等级；给了 `level_scores` 还会算出综合得分 `score` 便于横向比较/排名。

**常见坑**：
- 隶属度矩阵怎么来的不交代——评委无法判断可信度，直接扣分
- 最大隶属度原则在两个等级隶属度接近时不稳健（如 0.34 vs 0.33），这时应改看综合得分或说明置信度
- 权重和不为 1（代码已自动归一化，但正文数据要对得上）
