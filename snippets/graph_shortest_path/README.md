# 图论（最短路 / 最小生成树 / 网络流）

**什么时候用**：题目本质是"节点+边"的网络结构（路网、物流、管网、通信网）。按问的是什么选函数：

| 题目在问 | 函数 |
|---|---|
| 两点间最短/最省路径 | `shortest_path` |
| 用最小总代价把所有点连通（铺管道/电缆/修路） | `minimum_spanning_tree` |
| 网络最大通过量（管网输送、通行能力上限） | `max_flow` |
| 在打满最大流的前提下费用最省 | `min_cost_max_flow` |

**参数怎么调**：核心是**权重的语义**——最短路里 weight 是距离/时间/成本，网络流里 capacity 是容量、weight 是单位流量费用，两者别混。权重定义错了结果没有意义。有向场景 `shortest_path` 要传 `directed=True`；`max_flow` 系列本身按有向图处理。

**结果怎么解读**：`shortest_path` 的 `length` 是路径总权重（不是跳数），`method` 显示实际用的算法（有负权时自动切 Bellman-Ford）；`minimum_spanning_tree` 的 `total_weight` 是最省总代价、`edges` 是选中的边；`max_flow` 的 `flow` 是每条边的实际流量分配，可直接做成论文里的方案表。

**常见坑**：
- 有向图当无向图建——方向错了结果就是错的，记得 `directed=True`
- 最短路的"权重"和网络流的"容量"混用
- 最小生成树只适用于无向图；有向的连通问题是最小树形图，不能直接套
- 图不连通 / 源汇点之间无通路时 networkx 会抛异常，先检查连通性
