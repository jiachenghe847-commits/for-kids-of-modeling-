# 马尔可夫链（状态转移预测）

**什么时候用**：系统在有限个"状态"之间随时间跳转，且**下一步只取决于当前状态、与更早历史无关**（无后效性）——天气晴雨转移、市场份额/品牌忠诚、设备好坏、信用等级迁移、人口在几个类别间流动等。要预测"长期会稳定成什么比例"或"n 步后处于各状态的概率"时特别合适。

**用法三步**：
1. `transition_matrix(sequence)`：从历史状态序列估出转移矩阵 P（若题目直接给了 P 就跳过这步）。
2. `stationary_distribution(P)`：求长期平稳分布——不管从哪开始，长期各状态的占比。
3. `n_step_distribution(P, initial, n)` / `predict_next(P, state)`：从某初始分布预测 n 步后，或预测下一步。

**参数怎么调**：无超参数。关键是 P 的来源要可靠——用频率估计时样本要足够多，否则 P 有偏；`initial` 是初始分布向量（和为 1），单一起始状态用 one-hot（如 `[1,0,0]`）。

**结果怎么解读**：`pi` 平稳分布是常见结论点（"长期市场份额稳定在 X:Y:Z"）；`stationary_distribution` 的 `eigenvalue` 应接近 1，明显偏离说明 P 不是合法的行随机矩阵。`n_step` 随 n 增大通常收敛到 `pi`。

**常见坑**：
- 无后效性不成立还硬套马尔可夫（下一步明显依赖更长历史时，模型失效或要用高阶马尔可夫）
- 转移矩阵每行必须和为 1，用频率估计时若某状态样本极少，P 那一行不可靠——正文要说明数据量
- 存在"吸收态"或多个不连通子链时，平稳分布不唯一，`pi` 结果依赖初值，要额外讨论
- 平稳分布当成"很快就会达到"——收敛速度取决于 P，最好用 `n_step` 画出收敛过程（配 `plotting`）
