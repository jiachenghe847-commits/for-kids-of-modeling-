# 智能优化算法（遗传算法 / 模拟退火）

**什么时候用**：目标函数非线性、多峰、不可导，或问题是组合优化（TSP、排班、选址、背包）——传统规划求解器失效或建不出标准型时的"兜底"全局优化。能写成线性/整数规划标准型的，优先用 `snippets/linear_programming/`（更快更可证明最优）。

**参数怎么调**：
- `genetic_optimize`（差分进化）通用性强、参数少，作为首选；`anneal_optimize`（模拟退火）适合更崎岖的多峰面。两者都求**最小化**，最大化就把目标取负，并返回可直接画收敛曲线的 `history`。
- `bounds` 决定搜索范围，给太宽收敛慢、太窄可能框掉最优，要根据问题物理含义定。
- `maxiter` 是精度/耗时的权衡；结果对随机种子敏感，论文里必须记录 `seed`，并跑多个种子看稳定性。
- `tsp_anneal` 是组合优化模板，输入距离矩阵即可，可仿照它改造成别的组合问题。

**结果怎么解读**：`x`/`objective` 是找到的最优解与目标值，`history` 是逐代最佳目标值，`seed` 和 `nit` 用于复现实验；差分进化另返回 SciPy 的群体收敛指标 `convergence`。这类算法**不保证全局最优**，正文要说明"启发式近似解"，并用 `snippets/model_validation.multi_seed_summary` 给出多次运行的最好、平均、标准差和最差结果。

**常见坑**：
- 只跑一次就报结果、不提随机性——评委会质疑稳定性，务必多种子重复
- 声称"求得最优解"——启发式只能说"近似最优/满意解"
- 目标函数忘了取负导致求成了最小/最大反向
- 组合问题规模大时耗时爆炸，要说明时间复杂度与终止条件
- 只画最后一次运行的收敛曲线、不保存原始 JSON——图只能作为展示，实验记录还应保留每代数值
