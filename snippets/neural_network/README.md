# BP 神经网络（回归预测 / 分类 / 综合评价）

**什么时候用**：输入输出关系复杂非线性、说不清机理但有足够样本时——预测（`bp_regress`）、分类（`bp_classify`），或作为 BP 综合评价（用网络拟合"指标→评分"映射）。样本量小（几十条以下）、或关系近似线性/指数，别上神经网络，用回归/灰色预测更稳、更好解释。

**参数怎么调**：
- 输入**必须标准化**——代码已用 `StandardScaler` 管道自动处理。
- `hidden` 隐藏层结构默认 `(16, 8)`：样本少就调小防过拟合，关系复杂再加宽/加深。
- `max_iter` 不收敛时（会有 warning）适当加大。
- 结果对 `seed` 敏感，论文必须记录随机种子。

**结果怎么解读**：回归看 `rmse`/`r2`，分类看 `accuracy`；`predict` 是可直接对新数据预测的函数。**注意这些是训练集指标，会偏乐观**——真实泛化能力必须用 `snippets/model_validation/` 的交叉验证或留出测试集来评。

**常见坑**：
- 只报训练集精度当成模型效果——最典型的过拟合陷阱，评委必查泛化/交叉验证
- 样本太少还硬上神经网络，几乎必过拟合
- 神经网络是黑箱，正文要么做特征重要性/敏感性分析，要么说明为何选它而非可解释模型
- 不标准化直接喂原始数据（本脚手架已规避，自己改动时注意）
