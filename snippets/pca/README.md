# 降维与相关（PCA / 因子分析 / 典型相关）

本目录含三个方法：`pca_reduce`·`pca_composite_score`（主成分）、`factor_analysis`（因子分析）、`canonical_correlation`（典型相关）。

**三者怎么选**：
| 你要做什么 | 用哪个 |
|---|---|
| 压缩指标维度、去共线、客观综合打分 | PCA |
| 提炼指标背后的「潜在因子」并解释其含义 | 因子分析 |
| 研究**两组**变量整体之间的相关性 | 典型相关分析 |

PCA 与因子分析的关键差异：PCA 的主成分是原始指标的线性组合（纯方差压缩）；因子分析反过来，假设指标由少数不可观测的公共因子驱动，更适合"这些指标背后其实在测什么"这类问题。

## 一、主成分分析（`pca_reduce` / `pca_composite_score`）

**什么时候用**：指标很多且彼此相关（共线），想压成几个互不相关的综合指标——用于降维、去共线、或作为客观综合评价打分（`pca_composite_score`）。指标之间独立、维度不高时不必上 PCA。

**参数怎么调**：
- `standardize=True` 是默认也是刚需：指标量纲/数量级不同时不标准化，PCA 会被大数值指标绑架。
- `n_components` 传整数保留固定个数；传小数（如 `0.9`）自动保留累计方差贡献率达 90% 的主成分——**推荐后者**，让数据决定。

**结果怎么解读**：`explained_ratio` 是每个主成分的方差贡献率，`cumulative_ratio` 累计到 0.85~0.95 一般就够；`components` 每一行是一个主成分在原始指标上的载荷，看哪些指标载荷大就能给主成分起名（论文里必须做这一步解释，否则主成分没有现实含义）；`pca_composite_score` 的 `score`/`rank` 是综合评价得分与排名。

**常见坑**：
- 不标准化直接 PCA——最常见的扣分点
- 主成分算完不做"经济/物理含义"解释，只堆数字——评委会认为没吃透
- 主成分得分有正负，是相对排名不是绝对分，正文里要说明"得分仅用于排序"
- 累计贡献率太低（<80%）还强行只取前两个主成分，信息丢太多

## 二、因子分析（`factor_analysis`）

**什么时候用**：想把一堆观测指标归纳成少数几个有现实含义的潜在维度（如把 10 项测评题归纳为"专业能力/沟通能力"两个因子）。

**参数怎么调**：`n_factors` 因子个数是关键，可先用 PCA 看碎石图/累计贡献率辅助决定；`standardize` 默认 True。

**结果怎么解读**：`loadings` 因子载荷是核心——某因子在哪些指标上载荷大（一般 >0.5），就按这些指标给因子命名，**这一步的解释是论文的重点**；`communality` 共同度表示该指标被公共因子解释的比例，太低（<0.3）说明该指标游离于因子结构之外。

**常见坑**：因子提取出来不命名、不解释含义，等于白做；因子数取太多导致每个因子只对应一两个指标，失去归纳意义。

## 三、典型相关分析（`canonical_correlation`）

**什么时候用**：有**两组**变量（如 X=经济指标组、Y=环境指标组），要问"这两个方面整体上相关吗、怎么相关"。单对单变量的相关用 `snippets/statistics/` 的 `correlation` 即可，不必上 CCA。

**参数怎么调**：`n_components` 提取几对典型变量，通常取 1-2 对；样本量应明显大于两组变量总数。

**结果怎么解读**：`correlations` 是各对典型变量之间的相关系数（第一对最大，最重要）；`x_weights`/`y_weights` 显示每组里哪些原始变量贡献最大，据此解释"是 X 组的哪几个指标在和 Y 组的哪几个指标呼应"。

**常见坑**：只报典型相关系数不解释权重结构；样本量不足时结果不稳定。
