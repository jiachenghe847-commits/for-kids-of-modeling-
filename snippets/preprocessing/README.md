# 数据预处理（缺失值 / 异常值 / 标准化 / 归一化）

**什么时候用**：几乎每道题拿到数据的**第一步**。聚类、PCA、TOPSIS、神经网络等对量纲和异常值敏感的方法，喂数据前必须先过这一关。论文里"数据预处理"通常是独立一小节，是评委看数据功底的地方。

**参数怎么调**：
- 缺失值 `fill_missing`：时间序列用 `interpolate`，独立样本用 `mean`/`median`（有极端值优先 median）；缺失比例大（>20%）时删列或说明处理策略，别硬填。
- 异常值 `detect_outliers`：`iqr` 稳健、对分布无假设，是默认首选；`zscore` 仅适合近似正态数据（记得把 `k` 设 3）。检出异常值后是删除、盖帽还是保留，要在正文说明依据，不能默默删。
- 标准化 vs 归一化：有离群点或做 PCA/聚类/回归用 `standardize`（Z-score）；需要固定到 [0,1]（如某些评价、神经网络输入）用 `normalize`。

**结果怎么解读**：各函数都返回还原所需的参数（`mean`/`std`、`min`/`max`），预测/评价完要把结果映射回原量纲时用得上。`n_filled`/`n_outliers` 要在正文报告"处理了多少条"。

**常见坑**：
- 悄悄删异常值/填缺失却不写进论文——数据可复现性存疑，评委扣分
- 对测试集/新数据用它自己的均值方差标准化，而不是训练集的参数——数据泄漏
- 分类标签列、ID 列也被一起标准化了
