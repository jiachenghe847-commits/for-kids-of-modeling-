# 回归 · 拟合 · 插值

**什么时候用**：变量间有函数关系需要量化、外推预测，或已知离散点要加密/填补中间值。
- 近似线性趋势 → `fit_linear`
- 曲线趋势 → `fit_polynomial`(多项式) 或 `fit_nonlinear`(指数/幂/对数等已知形式)
- 关系非线性、说不清函数形式、又有离群点 → `svr_fit`(支持向量机回归)
- 只想在已知点之间插值、不推断规律 → `spline_interpolate`

**回归 vs 插值的区别（别用错）**：回归是"找一条规律曲线穿过点云趋势"，允许偏离数据点、可外推；插值是"曲线严格过每个已知点"，只在已知范围内加密、**不能外推**。预测未来用回归，补全缺失点用插值。

**参数怎么调**：
- `fit_polynomial` 的 `degree` 从 1 开始加，画残差图看趋势是否消失；超过 3 阶通常是过拟合信号。
- `fit_nonlinear` 要自己给函数形式 `func(x, *params)` 和初值 `p0`；初值给不好会不收敛，先根据物理含义估个量级。
- `spline_interpolate` 默认三次样条最光滑；数据有噪声时样条会把噪声也插进去，这时该用回归而非插值。
- `svr_fit` 的 `C` 越大越贴合训练数据（过拟合风险），`epsilon` 是容忍带宽度；`kernel="rbf"` 处理非线性，线性关系用 `"linear"`。SVR 是黑箱，给不出可写进正文的解析式，需要公式表达时用前面几个。

**结果怎么解读**：`r2` 越接近 1 拟合越好，但高 `r2` 不代表外推可靠——外推要在正文说明范围和风险；各函数都返回 `predict`/`interp` 可对新点求值。

**常见坑**：
- 数据点太少（<10）时 `r2` 虚高，不能只看 `r2` 下结论
- 拿插值当预测做外推——插值在数据范围外会剧烈发散，是典型错误
- 变量间不是线性关系时强行线性拟合，要先看散点图
- 强行高阶多项式把 `r2` 刷到 1（过拟合），残差图会暴露
