# 统计分析（假设检验 / 方差分析 / 卡方 / 相关 / 区间估计）

**什么时候用**：数据分析型题目（尤其 C 题）里，需要用数据**支撑一个结论**时——"这两组有没有差别""这几个因素有没有影响""这两个变量相不相关"。是描述性统计之外、把"看起来像"变成"统计上显著"的一步。

**各方法怎么选**：
| 你想回答 | 方法 |
|---|---|
| 某组均值是否等于某个值 / 两组均值是否有差异 | `t_test` |
| 三组及以上均值是否有差异 | `anova` |
| 两个分类变量是否相关（如性别 vs 是否购买） | `chi_square` |
| 两个连续变量的相关强度与方向 | `correlation` |
| 数据是否近似正态（做 t 检验/ANOVA 前的前提检查） | `normality_test` |
| 某个结果的 95% 置信区间（填进结果表） | `confidence_interval` |
| 结果的相对离散程度、跨量纲比稳定性 | `coefficient_of_variation` |
| 中位数/分位数等没有解析分布的量的区间 | `bootstrap_ci` |

**区间估计怎么用**：论文里只给点估计不给区间，评委没法判断这个数有多可靠——获奖论文的结果表普遍带 95% CI 一列。默认用 `confidence_interval`（t 区间）；样本量小又明显偏态、或者要给中位数这类统计量配区间时改用 `bootstrap_ci`（BCa 校正，**必须传 `seed`**，否则同一份数据两次运行结果不同，论文就不可复现了）。`coefficient_of_variation` 给的是相对离散度，好处是跨量纲可比——「厚度标准差 0.17 µm」说明不了什么，「CV = 2.8%」才能和别的量放一起看。经验刻度：CV < 3% 重复性优秀，3%~5% 良好，5%~10% 基本可接受，> 10% 提示模型或数据处理有问题。均值接近 0 时 CV 会被分母放大成任意值，函数把 `meaningful` 置为 False，这种情况别往论文里填。

**结果怎么解读**：核心看 `p_value` 和 `significant`（默认 `alpha=0.05`）。`p < 0.05` → 有统计显著性（拒绝"无差异/独立"的原假设）；`p >= 0.05` → 证据不足，**不能说"没有差异"**，只能说"没检测到显著差异"。`correlation` 的 `r` 还给出相关强度（±0.8 以上强，0.3 以下弱）和方向。

**常见坑**：
- 只看均值大小就下"A 比 B 好"的结论，不做显著性检验——评委会问"差异是不是偶然"
- p 值当成"效应大小"——p 小只说明"更可能非偶然"，不代表差异大；差异大小要看均值差/相关系数本身
- 用 pearson 去测非线性/有离群点的关系——这时该用 spearman
- t 检验/ANOVA 默认数据近似正态且（ANOVA）方差齐，样本偏态严重时先做 `normality_test`，不满足要改用非参数检验（秩和检验等，本脚手架暂未含）
