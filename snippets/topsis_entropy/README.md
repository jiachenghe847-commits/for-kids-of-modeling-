# TOPSIS / 熵权法

**什么时候用**：评价类问题，多个方案在多个指标上打分，需要给出综合排名；熵权法用于客观确定权重（区别于 AHP 的主观打分），两者可以结合（熵权法定权重，TOPSIS 排序）。

**参数怎么调**：输入矩阵前先统一指标方向（越大越好 / 越小越好要统一处理）；没有其他超参数。**成本型指标优先用倒数法 $1/x$，不要用 $\max(x)-x$**——理由见下方「常见坑」第 3 条，这个选择会显著改变权重。

**结果怎么解读**：`topsis_score` 越接近 1 越优；权重（`entropy_weights`）反映的是"哪个指标在样本里区分度大"，不代表指标本身重要性，正文里要说明这一点，不要和 AHP 的主观权重混为一谈。

**常见坑**：
- 指标方向不统一（比如成本类指标没有取反）直接扔进去算，排名会反直觉
- 熵权法在样本量很小（比如只有 3-4 个方案）时权重会不稳定，样本少时优先用 AHP
- **用 $\max(x)-x$ 做正向化会让该指标的权重畸高**。$\max(x)-x$ 把这一列平移到以 0 为下界，变异系数被人为放大，熵变小、权重暴涨；倒数法 $1/x$ 保持原有相对尺度，不引入人造的 0 下界。实测（3 个指标、每组 200 次随机模拟，理想权重应在 0.33 附近）：

  | 方案数 n | $\max(x)-x$ 的最大权重 | $1/x$ 的最大权重 |
  |---|---|---|
  | 3 | 0.949 | 0.571 |
  | 10 | 0.887 | 0.430 |
  | 30 | 0.859 | 0.385 |

  注意这**不是**样本量问题——n=30 时 $\max(x)-x$ 依然给出 0.859。最坏情况下最优方案的成本恰为最大值，正向化后该格为 0，权重可达 0.99，综合排序等于被单一指标绑架。写进正文时要说明用了哪种正向化方式，评委会问。
